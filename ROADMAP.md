# Nabira roadmap

Это направление развития, а не обещание конкретных дат. Приоритет меняется по результатам реального
использования и воспроизводимых баг-репортов.

## Надёжность ввода

- одинаковое поведение конвертации на macOS и Windows;
- регрессионные тесты для мессенджеров, браузеров, редакторов и виртуальных машин;
- защита имён, сокращений, кода, идентификаторов и разговорных повторов от ложных замен;
- стабильная конвертация выделенного текста и всей строки.

## Локальная языковая модель

- отдельная добровольная загрузка модели из настроек;
- контекстное исправление выбранной строки без отправки текста на сервер;
- понятный статус модели, проверка целостности и безопасное удаление;
- оценка качества на открытом наборе RU/EN примеров.

## Доставка и доверие

- прозрачные SHA-256 и подписанные фиды обновлений;
- доверенная подпись Windows после появления подходящего сертификата или одобрения программы для OSS;
- Developer ID и notarization для macOS, если они станут доступны владельцу проекта;
- публикация через системные каталоги пакетов после стабилизации установщиков.

## Сообщество

- публичная очередь ошибок и предложений;
- пометки `good first issue` для небольших изолированных задач;
- воспроизводимые инструкции сборки и тестирования;
- регулярные release notes с известными ограничениями.
