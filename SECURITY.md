# Security policy

## Reporting a vulnerability

Не публикуйте уязвимость в обычном GitHub issue. Напишите на
[mitfleg@icloud.com](mailto:mitfleg@icloud.com) и укажите:

- затронутую платформу и версию Nabira;
- понятные шаги воспроизведения;
- возможное влияние;
- минимальный безопасный пример или proof of concept.

Не отправляйте реальные пароли, токены, закрытые ключи или содержимое чужой переписки. Дайте
владельцу проекта время подтвердить проблему и подготовить исправление до публичного раскрытия.

## Trust boundaries

Nabira обрабатывает набранный текст локально. Сеть используется для аккаунта, trial, подписки,
проверки обновлений и загрузки файлов. Официальные сборки публикуются через
[nabira.site](https://nabira.site/) и GitHub Actions этого репозитория.

Текущий статус Windows-подписи, контроль целостности и модель релизов описаны в
[CODE_SIGNING_POLICY.md](CODE_SIGNING_POLICY.md).
