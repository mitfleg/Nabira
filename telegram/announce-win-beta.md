🪟 Nabira теперь и под Windows — открытая бета!

Та же идея, что и на macOS: исправляет текст, набранный не в той раскладке. Открытый код, без телеметрии.

⬇️ Установка:
• Скачайте Nabira-Setup-0.9.0.exe (установщик) со страницы релиза:
https://github.com/mitfleg/Nabira/releases/tag/win-v0.9.0
• Есть и portable-версии (x64 / ARM64) — без установки.
• Windows покажет синее окно «Windows protected your PC» — сборка пока без подписи. Нажмите «Подробнее» → «Выполнить в любом случае». Для беты это нормально.

⌨️ Как работает:
• Значок в трее → правый клик → «Settings».
• Триггер по умолчанию — двойной Ctrl. Набрали слово не в той раскладке → дважды нажмите Ctrl → оно превратится в правильное, и раскладка переключится.
• Двойной Ctrl без набора = отменить последнюю конвертацию.
• В настройках: конвертация всей строки, умная конвертация выделения, авто-конвертация при наборе (бета), хоткей смены раскладки, память раскладки по приложению, звук, автозапуск.

🔄 Приложение само проверяет обновления. 🐛 Баги и идеи: https://github.com/mitfleg/Nabira/issues

🪟 Nabira is now on Windows — open beta!

Same idea as on macOS: it fixes text typed in the wrong keyboard layout. Open source, no telemetry.

⬇️ Install:
• Download Nabira-Setup-0.9.0.exe (installer) from the release page:
https://github.com/mitfleg/Nabira/releases/tag/win-v0.9.0
• Portable builds (x64 / ARM64) are also available — no install needed.
• Windows will show “Windows protected your PC” — the build isn't code-signed yet. Click “More info” → “Run anyway”. This is expected for a beta.

⌨️ How it works:
• Tray icon → right-click → “Settings”.
• Default trigger is double-tap Ctrl. Typed a word in the wrong layout? Double-tap Ctrl → it converts and switches the keyboard.
• Double-tap Ctrl with nothing typed = undo the last conversion.
• In settings: whole-line conversion, smart selection conversion, as-you-type auto-conversion (beta), a layout-switch hotkey, per-app layout memory, sound, launch at startup.

🔄 The app checks for updates itself. 🐛 Bugs & ideas: https://github.com/mitfleg/Nabira/issues
