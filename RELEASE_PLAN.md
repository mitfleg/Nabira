# План Nabira до релиза 1.0

## Принцип распространения

- Nabira разрабатывается, продаётся и обновляется без обязательной зависимости от Apple Developer Program.
- Для macOS публикуем DMG/ZIP, SHA-256 и независимо подписанный манифест обновления.
- Без Apple notarization пользователь один раз подтверждает запуск через «Конфиденциальность и безопасность → Всё равно открыть».
- Apple Developer ID остаётся необязательным улучшением на будущее, а не условием работы продукта.

## Этап 1. Готовая продуктовая оболочка

- [x] Бренд Nabira в приложении, bundle ID, сборках, установщиках и репозитории.
- [x] Современное меню и окно настроек.
- [x] Пробный период семь дней без обязательной регистрации.
- [x] Локальные вход, регистрация, подтверждение email и восстановление пароля.
- [ ] Полная проверка первого запуска, разрешений и переноса настроек со старой сборки.
- [ ] Русская и английская локализация всех новых экранов и ошибок.
- [ ] Windows: перенести аккаунт, семидневный trial и проверку подписки из macOS-клиента.
- [ ] Windows: хранить refresh token через Windows Credential Manager или DPAPI, а не в `settings.json`.

## Этап 2. Надёжность основного функционала

- [ ] Матрица ручных тестов: ChatGPT, Telegram, браузеры, IDE, Office, терминалы и удалённый рабочий стол.
- [ ] Тесты на Intel и Apple Silicon, а также на поддерживаемых версиях macOS.
- [ ] Windows beta: тесты на Windows 10/11 x64 и Windows 11 ARM64.
- [ ] Безопасное поведение в полях паролей, банковских формах и при Secure Input.
- [ ] Отмена последнего автоматического исправления и понятная обратная связь пользователю.
- [ ] Экспорт, импорт и сброс пользовательских словарей и самообучения.
- [ ] Нагрузочные тесты: потребление CPU/RAM, длинный непрерывный ввод и восстановление после сбоев.

## Этап 3. Сервер и аккаунт

- [x] Отдельный backend-репозиторий.
- [x] Регистрация, вход, refresh/logout, подтверждение email и сброс пароля.
- [ ] Production-инфраструктура: домен, HTTPS, секреты, PostgreSQL, резервные копии и мониторинг.
- [ ] Серверная лицензия: trial, активная подписка, grace period, блокировка после окончания доступа.
- [ ] Ограничение частоты запросов, аудит сессий и принудительный выход со всех устройств.
- [ ] Политика приватности: хранить минимум данных и не отправлять набираемый текст на сервер.
- [ ] macOS: хранить только access/refresh tokens в Keychain с режимом `WhenUnlockedThisDeviceOnly`; пароль не сохранять.
- [ ] Сохранить зашифрованную офлайн-копию стабильного сертификата Nabira: смена ключа меняет идентичность приложения для Keychain и системных разрешений.

## Этап 4. Оплата и подписка

- [ ] Выбрать доступного в России платёжного провайдера и проверить его условия непосредственно перед подключением.
- [ ] Веб-страница оплаты вне приложения.
- [ ] Webhook с проверкой подписи, идемпотентностью, возвратами и повторными платежами.
- [ ] Тарифы, чеки, отмена подписки и понятное состояние оплаты в приложении.
- [ ] Серверные тесты всех переходов статуса подписки.

## Этап 5. Безопасные обновления без Apple

- [ ] Отдельный Ed25519-ключ релизов; закрытый ключ хранится только в защищённом CI/офлайн-хранилище.
- [ ] Подписанный манифест: версия, URL, SHA-256, размер, минимальная версия ОС и подпись.
- [ ] Приложение проверяет подпись и хэш до установки, не доверяет одному HTTPS.
- [ ] Атомарная установка обновления, резервная копия текущей версии и автоматический откат.
- [ ] Пошаговая инструкция первого запуска без notarization.
- [ ] Для Windows — отдельная проверка SmartScreen и вариант сертификата подписи кода.

## Этап 6. Юридическая и коммерческая готовность

- [ ] Проверка товарного знака и домена Nabira перед рекламой.
- [ ] Лицензия продукта, пользовательское соглашение, политика конфиденциальности и правила возврата.
- [ ] Аудит лицензий словарей, OpenCorpora и остальных сторонних компонентов.
- [ ] Сайт, база знаний, Telegram поддержки `@mitfleg` и email `mitfleg@icloud.com`.
- [ ] Система обращений и опциональная отправка обезличенных crash-отчётов только с согласием.

## Этап 7. Выход

1. Внутренняя alpha: ежедневное использование без критических ошибок.
2. Закрытая beta: 20–50 пользователей, сбор проблем по приложениям и версиям macOS.
3. Платная beta: реальные оплаты, продление, отмена и восстановление доступа.
4. Release candidate: заморозка функций, полный регресс, проверка установки и обновления.
5. Nabira 1.0: поэтапная выдача обновления и готовый план отката.

## Обязательные ворота перед 1.0

- Нет потери или неправильной отправки текста в поддерживаемых приложениях.
- Backend, оплата и восстановление доступа проверены на production-подобном окружении.
- Обновление нельзя подменить без закрытого Ed25519-ключа.
- Есть резервные копии, мониторинг, поддержка и процедура отката.
- Установка без Apple Developer ID описана и проверена на чистом Mac.
